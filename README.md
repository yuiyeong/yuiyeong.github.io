# 소개

이 블로그는 제 개인적인 생각, 프로젝트, 그리고 개발 관련 경험을 공유하기 위한 공간입니다. 

Jekyll과 GitHub Pages를 활용하여 쉽고 효율적으로 콘텐츠를 관리하고 있습니다.

## 기술 스택

- [Jekyll](https://jekyllrb.com/): 정적 사이트 생성기
- [Chirpy 테마](https://github.com/cotes2020/jekyll-theme-chirpy): 깔끔하고 반응형 디자인을 제공하는 Jekyll 테마
- [GitHub Pages](https://pages.github.com/): 웹사이트 호스팅
