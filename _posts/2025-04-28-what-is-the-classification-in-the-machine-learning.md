## 🚀 TL;DR

- 머신러닝 분류 모델은 데이터를 여러 클래스로 구분하는 알고리즘이다
- **이진 분류**는 로지스틱 함수를 사용해 확률을 [0,1] 범위로 모델링한다
    - 출력값이 참/거짓(0/1) 두 가지로만 나오는 가장 기본적인 분류 형태이다
    - 로지스틱 회귀는 이름에 '회귀'가 들어가지만 실제로는 분류 모델이다
    - Binary Cross Entropy (BCE) 손실함수를 사용하며, 이는 잘못된 예측에 강한 패널티를 부여한다
    - 질병 검사의 양성/음성 판정, 스팸메일 필터링 등이 대표적인 예시이다
- **다중 분류**에서는 소프트맥스 함수를 통해 여러 클래스에 대한 확률 분포를 계산한다
    - 클래스가 k개인 경우, 원 핫 인코딩으로 클래스 레이블을 표현한다
    - 소프트맥스 함수는 logit 벡터를 각 클래스에 속할 확률 벡터로 변환한다
    - 모든 출력값의 합은 1이 되어 확률 분포를 형성한다
    - 이산형 변수라도 값의 의미가 수치적인 경우 회귀로 모델링이 더 유리할 수 있다
- 분류 모델은 크로스 엔트로피 손실함수를 사용하며, 이는 확률 모델링에 이론적으로 최적화되어 있다
- kNN은 간단하고 직관적이지만 계산 비용이 높고 차원의 저주에 취약하다
- 결정 트리는 해석하기 쉽고 전처리 요구사항이 적지만 과적합 경향이 있다
- 랜덤 포레스트는 여러 결정 트리의 앙상블로 과적합에 강하고 높은 정확도를 제공한다
- SVM은 마진을 최대화하는 결정 경계를 찾으며 커널 트릭을 통해 비선형 문제도 해결할 수 있다
- 각 모델은 고유한 장단점을 가지며 데이터 특성과 문제에 따라 적절한 선택이 필요하다

## ⚖️ 이진 분류 문제

- **이진분류(Binary Classification)**: 출력값이 **참 혹은 거짓(또는 0/1)** 두 가지로만 나오는, 가장 간단한 형태의 분류 모델
- 즉, 데이터를 두 개의 class(범주)로 구분하는 문제
- 대표적인 이진분류 예시)
	- 질병 검사의 양성/음성 판정
	- 스팸메일 필터링

### 확률의 모델링과 로지스틱 함수

- 이진 분류 문제에서는 어떤 샘플이 **특정 클래스에 속할 확률** 을 모델링하는 것이 중요
- 단순히 0 또는 1로 예측하는 것보다, 예측의 확실성(confidence)을 나타낼 수 있는 확률값을 제공하는 것이 실용적
- 선형 회귀 모델($$\hat{y} = w^T x + b$$)은 확률을 모델링하기에 적합하지 않다.
	- 선형 회귀는 음수나 1보다 큰 값을 출력할 수 있음
	- 학습이 불안정하다.
	- 확률은 항상 [0, 1] 범위 내에 있어야 함

***이 문제를 해결하기 위해 로지스틱 함수(시그모이드 함수)를 도입하는것이다.***

![선형 회귀와 로지스틱 회귀](/assets/img/2025-04-28/img_linear_regression_and_logistic_regression.png){: .w-75 .center}

## ƒ 로지스틱(Logistic) 함수

- 로지스틱 함수는 어떤 실수값도 [0, 1] 사이의 값으로 변환해주는 S자 모양의 함수

$$ \sigma(z) = g(x) = \frac{1}{1 + e^{-x}} = \frac{e^x}{e^x + 1} $$

$$Logistic: \mathbb{R} \longrightarrow (0,1) $$
$$x \mapsto \frac{1}{1 + e^{-x}}$$


- 이 함수는 다음과 같은 특성을 가진다.
	- $$z$$가 매우 큰 양수일 때, $$\sigma(z) \approx 1$$
	- $$z$$가 매우 작은 음수일 때, $$\sigma(z) \approx 0$$
	- $$z = 0$$일 때, $$\sigma(0) = 0.5$$

![로지스틱 함수](/assets/img/2025-04-28/img_visualization_of_logistic_function.png){: .w-75 .center}

- 이 함수는 시그모이드(Sigmoid) 함수의 일종으로, S자형 곡선 그래프가 특징

> 시그모이드 함수란, S 자형 곡선 그래프가 나오는 함수를 일컫는다. 그런데 딥러닝 분야에서는, *시그모이드 함수라고 하면 보통 로지스틱 함수를 말한다.*
{: .prompt-tip}

## 1️⃣ 0️⃣ 로지스틱 회귀모델

> 로지스틱 회귀는 이름에 '회귀'가 들어가지만, 실제로는 분류 모델이다! 하지만, 이 로지스틱 회귀 모델을 **정답이 1일 확률을 예측하는 회귀 모델** 이라고도 이해할 수도 있다.
{: .prompt-tip}


일반 선형회귀가 다음과 같은 모델을 사용한다면,

$$ f_{a,b}: \mathbb{R} \longrightarrow \mathbb{R}, \quad x \longmapsto ax + b $$

로지스틱 회귀는 선형 모델에 로지스틱 함수를 적용하여,

$$ f_{a,b}: \mathbb{R} \longrightarrow (0,1), \quad x \longmapsto \frac{1}{1 + e^{-(ax+b)}} $$

이렇게 변형된 모델에서 학습을 진행한다.

즉, 로지스틱 회귀 모델은 선형 함수의 출력을 로지스틱 함수에 통과시켜 확률을 예측한다.

$$ P(y=1|x) = \sigma(w^T x + b) = \frac{1}{1 + e^{-(w^T x + b)}} $$

$$ P(y=1|x) $$: 입력 $x$ 가 주어졌을 때 클래스 1에 속할 확률

> 학습 과정에서 모델은 실제 클래스 레이블과 예측된 확률 간의 차이를 최소화하는 $$w$$와 $$b$$를 찾는다.
{: .prompt-tip}

## 🎓 로지스틱 회귀모델의 학습

로지스틱 회귀모델의 학습에는 **크로스엔트로피(Cross Entropy)** 손실함수를 사용한다. 

이 손실함수는 로지스틱 함수를 통과한 모델의 출력값(확률)에 적합하게 설계되었다.

이진 분류 문제에서는 **Binary Cross Entropy (BCE)** 를 사용한다.

$$ Loss_{BCE}: \{0,1\}, (0,1) \longrightarrow \mathbb{R}$$
$$ y, \hat{y} \longmapsto -(y \log \hat{y} + (1-y) \log (1-\hat{y}))  $$

위 수식이 복잡해 보이지만, 사실 라벨 y 는 0 또는 1 을 갖기 때문에 식이 간단해진다.
- 라벨 y 가 1 일 때,
$$-y \log \hat{y} $$
- 라벨 y 가 0 일때,
$$ -\log (1-\hat{y}) $$

![BCE 실제로 계산해보기](/assets/img/2025-04-28/img_real_calculation_of_bce.png){: .w-75 .center}

### 이진 분류 문제에서 손실함수로 MSE 대신 BCE 를 사용하는 주요 이유
	
- 예측이 완전히 틀린 경우, BCE 는 매우 큰 패널티를 부여
	- 예측이 틀렸을 때, **더 강력하고 정보가 풍부한 기울기를 제공** 해서, **빠르게 모델을 올바른 방향으로 조정** 할 수 있도록한다.
- 예측이 정답에 근접할 때, MSE 는 학습 속도가 매우 느려짐
- 로지스틱 함수와 BCE를 결합하면 미분식이 매우 간단해진다.
	- 최종적으로 $$\hat{y} - y$$ 형태

*즉, BCE 를 손실함수로 사용해서 학습을 했을 때 더 학습이 잘 된다!*

## 🎯 다중 분류 문제의 모델링

**다중 분류 문제** 는 **클래스가 k개인 경우** 를 말하며, *출력값은 i번째 원소가 i번째 클래스가 정답일 확률을 나타내는 k차 벡터 형태* 가 된다.

### 원 핫 인코딩(One Hot Encoding)

여기서 중요한 개념은 **원 핫 인코딩(One Hot Encoding)** 으로 클래스 레이블을 적절히 표현할 수 있다는 점이다.

정답 클래스가 i번째일 경우 **i번째 원소만 1이고, 나머지 모든 값이 0인 벡터** 로 라벨을 표현하는 방식이다.

즉, 각 클래스를 고유한 이진 벡터로 변환하는 기법이다.

예를 들어, 3개의 클래스가 있다면,
- 클래스 0 → [1,  0,  0]
- 클래스 1 → [0, 1, 0]
- 클래스 2 → [0, 0, 1]

### 소프트맥스(Softmax)
> **왜 필요할까?** 여러 클래스에 대한 확률을 계산하려면, 모든 확률의 합이 1이 되어야 한다. 소프트맥스는 여러 값을 확률 분포로 변환한다.
{: .prompt-tip}

- 소프트맥스 함수는 다중 분류 문제에서 로지스틱 함수의 일반화 버전이다.
- 다중분류 모델에서는 **소프트맥스(Softmax)** 함수를 사용하여 logit 벡터를 확률 벡터로 변환한다.
- 즉, 이 함수는 **여러 실수값을 입력**으로 받아 **각 클래스에 속할 확률을 출력**한다.

$$ Softmax: \mathbb{R}^k \longrightarrow (0,1)^k$$

$$  \vec{z} \longmapsto \vec{p}  $$

$$ \vec{z} = [z_o, z_1,\ ...,\ z_{k-1}] $$

$$\vec{p} = [p_0, p_1,\ ...,\ p_{k-1}] \in (0, 1)^k$$

- 여기서 각 확률값($$p_i$$)은,

$$ p_i = \frac{e^{z_i}}{\sum_{i=0}^{k-1} e^{z_i}} $$

- 소프트맥스 함수의 주요 특성으로는,
	- 모든 출력값이 0 과 1 사이
	- 모든 출력값의 합은 1 로, 확률 분포 형성
	- 상대적인 크기 관계가 유지된다.

**예시)**
이미지가 개, 고양이, 토끼일 가능성을 모델이 계산했다고 가정해보자.

- 개: 2.5
- 고양이: 1.2
- 토끼: 0.8

이 값들(이 원시 값을 logit 이라고 부른다)은 확률이 아니다. 

그래서 소프트맥스를 적용하면,
- 개: 70%
- 고양이: 20%
- 토끼: 10%
이렇게 확률 분포로 변환이 된다.

### 크로스 엔트로피(Cross Entropy)

손실함수로 **Cross Entropy (CE)** 를 사용한다.

로지스틱 함수를 통과한, 확률(모델의 출력값)에 대해 적용하도록 만들어진 손실함수

$$ Loss_{CE}: \{0,1\}^k, (0,1)^k \longrightarrow \mathbb{R} $$

$$ y, \hat{y} \longmapsto -\sum_{i=0}^{k-1} y_i \log \hat{y}_i $$

여기서,
- $$y_i$$ 는 원 핫 인코딩된 실제 클래스 (클래스 i에 대해 1, 나머지는 0)
- $$\hat{y_i}$$ 는 클래스 i에 대한 예측 확률
- $$K$$ 는 클래스의 총 개수

> **Cross Entropy 가 확률 모델링에 적합한 이유**
>
>- **이론적 근거**
>    - 정보 이론에 기반하여 확률 분포 간의 차이를 직접 측정
>    - 최대 가능도 추정(Maximum Likelihood Estimation)과 수학적으로 동일하여 통계적으로 견고함
>    - 다양한 확률 분포(베르누이, 다항)와 자연스럽게 연결됨
>- **실용적 이점**
>    - 잘못된 예측에 대해 더 강한 패널티(특히 높은 확신을 가진 잘못된 예측)
>    - 경사 하강법 과정에서 더 나은 기울기 특성
>    - 비선형 결정 경계 학습에 더 효과적
>    - 확률적 해석이 가능하여 모델의 불확실성 표현에 적합
>- **경험적 증거**
>    - 분류 문제에서 MSE보다 일반적으로 더 빠른 수렴과 더 높은 정확도
>    - 대부분의 현대 분류 모델에서 표준 손실 함수로 채택됨
>
>모든 분류 문제에서 크로스 엔트로피가 항상 최적의 선택인 것은 아니지만, 이론적 근거와 실용적 이점을 고려할 때 기본적인 선택으로 권장된다. 특히 확률적 분류가 필요한 경우(단순한 클래스 레이블이 아닌 확률이 필요한 경우)나 클래스 불균형이 있는 상황에서 더욱 그렇다.
{: .prompt-tip}

### 이산형 변수의 다중분류 모델링

데이터의 특성에 따라 분류와 회귀 중 어떤 접근 방식이 적합한지 결정해야 한다. 

그런데 이미지 속 사과의 개수를 세는 문제(이산형 변수)를 분류로 모델링하면 다음과 같은 문제가 발생할 수 있다.

- 최대 개수 설정이 필요함
- 오답들 사이에 차이를 둘 수 없음 (정답이 3일 때, 2로 예측 vs 0으로 예측의 차이를 구분하지 못함)

따라서 이산형 변수라도 값의 의미가 수치적인 경우, 회귀 문제로 모델링하는 것이 더 유리할 수 있다.

## 🧠 kNN 분류기

**k-최근접 이웃(k-Nearest Neighbor)** 알고리즘은 단순하지만 강력한 분류 방법이다.

새로운 데이터 포인트가 주어졌을 때, 학습 데이터셋에서 가장 가까운 k개의 이웃을 찾고 그들의 클래스를 기반으로 분류를 수행하는 매우 간단한 방법이다.

### kNN 의 핵심 아이디어
1. 입력 데이터 포인트와 모든 학습 데이터 간의 거리를 계산
2. 가장 가까운 k개의 이웃을 선택
3. 다수결 투표로 클래스 결정(또는 가중 투표)

- 가장 가까운 5개 샘플의 클래스 중 가장 많은 것으로 분류

![기본 그래프](/assets/img/2025-04-29/img_knn_ex03.png){: .w-75 .center}

- 가장 가까운 데이터들의 클래스 중 가장 많은 클래스가 *클래스 A* ! 즉, 새로운 데이터는 클래스 A 로 정해진다.

![기본 그래프](/assets/img/2025-04-29/img_knn_ex04.png){: .w-75 .center}

### 알고리즘 작동 방식

1. 거리 메트릭 선택 (유클리디안, 맨해튼, 민코프스키 등)
2. 새 데이터 포인트와 모든 훈련 샘플 간의 거리 계산
3. 가장 가까운 k개의 이웃 선택
4. 다수결 투표를 통해 클래스 결정 (또는 확률 계산)

### 장점

- 구현이 간단하고 이해하기 쉬움
- 비모수적(non-parametric) 접근법으로 복잡한 결정 경계 학습 가능
- 새로운 훈련 데이터 추가가 용이함
- 이론적 가정이 적음

### 단점

- 계산 비용이 높음 (특히 대용량 데이터셋)
- 차원의 저주에 취약함 (데이터가 고차원일수록 문제가 생김)
- 특성 스케일에 민감함
- **최적의 k 값** 선택이 필요함(이 최적의 k 를 찾도록 학습을 시킬 수 있음)

> 실질적인 문제가 kNN 으로 해결되는 경우는 거의 없다. 실제로는 고도화된 방법으로 학습한 모델과 성늘을 비교할 수 있는 baseline 으로서 사용이 된다. 즉, 모델을 학습 시켰다면 최소한 kNN 보다는 성능이 잘 나와야하는 것!
{: .prompt-tip}

## 🌲 결정 트리

**결정트리(Decision Tree)** 는 일련의 질문을 통해 데이터를 분류하는 모델이다. 즉, 데이터를 분할하는 일련의 규칙을 학습하여 분류 또는 회귀 문제를 해결하는 모델이다.

다시 말해서 결정트리는,
- 독립변수(X) 내의 대소 관계나 특정 임계값(Threshold)과의 비교 등에 대한 
	- **특정 특성에 대한 질문**
- 판단을 계층적으로 적용하여 최종 결과를 분류하는 모델이다. 
	- **답변**

결정트리 마치 스무고개와 유사한 방식이다.

> 트리 구조는 인간이 해석하기 쉬운 규칙 기반 표현을 제공하면, 학습이 끝난 후 시각화도 할 수 있다!
{: .prompt-tip}

### 구성 요소
- **루트 노드(Root Node)**: 트리의 시작점
- **내부 노드(Intermediate Node)**: 특성에 대한 테스트
- **리프 노드(Leaf Node, Terminal Node)**: 클래스 레이블 또는 예측값
- **가지(Branch)**: 테스트 결과에 따른 경로


### 학습 과정

결정트리 학습에서 중요한 개념은 **불순도(Impurity)** 로, 한 범주 안에 데이터가 얼마나 섞여 있는지를 측정한다. 

![불순도 개념 시각화](/assets/img/2025-04-29/img_impurity_example.png){: .w-75 .center}

불순도를 최소화하는 방향으로 트리를 구성한다.

1. 최적의 특성과 분할 지점 선택 (정보 이득 또는 지니 불순도 기준)
2. 데이터를 두 개 이상의 하위 집합으로 분할
3. 각 하위 집합에 대해 재귀적으로 과정 반복
4. 종료 조건 만족 시 리프 노드 생성

### 불순도 측정 방법

#### 엔트로피(Entropy)

엔트로피는 정보 이론에서 유래한 불순도 측정 방법으로, 주어진 데이터 세트의 무질서도를 측정한다.

##### 수학적 정의

노드 내 클래스 $$c$$에 대한 엔트로피 $$H(S)$$는 다음과 같이 계산됩니다.

$$ H(S) = - \sum_{i=1}^{c}p_ilog_2(p_i)$$

여기서,

- ​$$p_i$$는 노드 내 클래스 $$i$$의 비율
- $$c$$는 총 클래스 수

**특징**
- 모든 샘플이 같은 클래스일 때 엔트로피는 0 (완전 순수)
- 모든 클래스가 균등하게 분포되어 있을 때 엔트로피는 최대 (가장 불순)
- 이진 분류에서 최대 엔트로피는 1 (50:50 분포)

##### 정보 이득(Information Gain)

결정 트리에서는 분할 전후의 엔트로피 차이인 **정보 이득** 을 계산한다.

$$IG(S, A) = H(S) - \sum_{v \in Values(A)}\frac{|S_v|}{|S|}H(S_v)$$

여기서,
- $$S$$는 현재 노드의 데이터 세트
- $$A$$는 분할에 사용할 속성
- $$S_v$$​는 속성 $$A$$의 값 $$v$$를 가진 데이터 부분집합

알고리즘은 ***정보 이득이 최대가 되는 속성을 선택해 분할을 결정***

#### 지니 계수(Gini Index)

지니 계수는 경제학에서 불평등도를 측정하는 데 사용되었던 개념에서 유래했으며, CART(Classification and Regression Tree) 알고리즘에서 주로 사용된다.
##### 수학적 정의

지니 불순도는 다음과 같이 계산된다.

$$ Gini(S) = 1 - \sum_{i=1}^{c}p_i^2 $$

여기서,

- ​$$p_i$$는 노드 내 클래스 $$i$$의 비율
- $$c$$는 총 클래스 수


**특징**
- 값이 0이면 완전히 순수한 노드 (모든 샘플이 같은 클래스)
- 이진 분류에서 최대 불순도는 0.5 (50:50 분포)
- 계산이 엔트로피보다 간단하고 빠름

##### 지니 이득(Gini Gain)

분할 후 **가중 평균 지니 계수가 감소하는 양** 으로 측정한다.

$$ GiniGain(S, A) = Gini(S) - \sum_{v \in Values(A)}\frac{|S_v|}{|S|}Gini(S_v) $$

### 엔트로피 vs 지니 계수 비교

#### 유사점

- 둘 다 노드의 불순도를 측정
- 값이 0일 때 완전히 순수한 노드
- 클래스가 균등하게 분포되어 있을 때 최대값

#### 차이점

|특성|엔트로피|지니 계수|
|---|---|---|
|계산 방식|로그 함수 사용|제곱합 사용|
|계산 복잡도|상대적으로 복잡|상대적으로 단순|
|분할 성향|더 균형 잡힌 트리 선호|큰 파티션 생성 선호|
|사용 알고리즘|ID3, C4.5|CART|
|다중 클래스 처리|매우 효과적|상대적으로 덜 효과적|

> **실제 사용시 고려사항**
>
>- 지니 계수는 계산이 빠르고 이진 분류에 효과적
>- 엔트로피는 다중 클래스 문제에 더 적합한 경향
>- 실무에서는 두 방법 모두 시도해보고 더 나은 성능을 보이는 방법 선택
>- 대부분의 경우 두 방법 간 성능 차이는 크지 않음
{: .prompt-tip}

### 결정트리의 장점

- 직관적이고 해석하기 쉬움
- 전처리 요구사항이 적음 (스케일링 불필요)
- 수치형 및 범주형 데이터 모두 처리 가능
- 비선형 관계 포착 가능

### 결정트리의 단점

- 과적합 경향이 있음
- 작은 데이터 변화에도 트리 구조가 크게 변할 수 있음
- 불균형 데이터셋에서 편향될 수 있음
- 회전된 결정 경계 표현에 비효율적

## 🌲🌳🌲 랜덤 포레스트

**랜덤 포레스트(Random Forest)** 는 여러 개의 결정트리를 생성하고 그 결과를 종합하는 앙상블 방법이다. 각 트리는 데이터의 다른 부분 집합과 특성 부분 집합을 사용하여 학습되므로, 다양성이 증가하고 과적합이 감소한다. 각 트리는 독립적으로 훈련되고, 최종 예측은 모든 트리의 예측을 종합하여 결정된다.

![랜덤 포레스트 개념 시각화](/assets/img/2025-04-29/random_forest.gif){: .w-75 .center}
[출처: https://blog.tensorflow.org/2021/05/introducing-tensorflow-decision-forests.html]
### 모델의 앙상블

앙상블 학습(Ensemble Learning)은 **여러 모델의 예측을 결합** 하여 단일 모델보다 더 나은 성능을 얻는 기법이다. 랜덤 포레스트는 **배깅(Bagging, Bootstrap Aggregating)** 앙상블의 대표적인 예다.

> 부트스트랩 집계(Bootstrap Aggregating) 를 배깅(bagging) 이라고 부른다. 배깅은 랜덤 포레스트 말고도 다양한 머신러닝 알고리즘에 적용할 수 있지만, 랜덤 포레스트가 대표적인 예시다.
{: .prompt-tip}

### 핵심 원리

1. **부트스트랩 샘플링**: 원본 데이터에서 무작위 샘플 생성 (중복 허용)
	1. 원본 데이터셋이 N개의 샘플을 가지고 있다고 가정
	2. 원본 데이터셋에서 복원 추출(중복 허용)로 N개의 샘플을 뽑아 새로운 데이터셋을 만든다.
	3. 이 과정을 여러 번 반복해 여러 개의 부트스트랩 데이터셋을 생성
	- 복원 추출의 특성상,
		- 일부 샘플은 여러 번 선택될 수 있다 (중복)
		- 일부 샘플은 전혀 선택되지 않을 수 있다
		- 통계적으로 각 부트스트랩 샘플은 원본 데이터의 약 63.2%의 고유 샘플을 포함
		- 선택되지 않은 약 36.8%의 샘플을 "Out-of-Bag(OOB)" 샘플이라고 부른다.
2. **무작위 특성 선택**: 트리의 각 노드에서 분할을 결정할 때 모든 특성이 아닌 무작위로 선택된 특성의 부분집합만 고려
    - 분류 문제: 보통 √p개의 특성 사용 (p는 총 특성 수)
    - 회귀 문제: 보통 p/3개의 특성 사용
3. **트리 성장**: 각 부트스트랩 샘플에 대해 결정 트리 생성 (보통 가지치기 없이 최대 깊이까지)
4. **예측 집계**: 모든 트리의 예측을 결합하여 최종 예측 도출
    - 분류: 다수결 투표
    - 회귀: 평균값

> 랜덤 포레스트는 기본적인 배깅(Bagging) 방법에 "특성 무작위 선택" 이라는 추가적인 단계를 넣은 것이다.
{: .prompt-tip}

### 랜덤 포레스트의 장점

- 과적합에 강함
- 높은 정확도
- 특성 중요도 제공
- 대규모 데이터셋에 효과적
- 결측치 처리 능력

### 랜덤 포레스트의 단점

- 결정 트리보다 해석이 어려움
- 훈련 시간이 더 길 수 있음
- 매우 고차원 희소 데이터에 비효율적일 수 있음
- 메모리 요구사항이 높을 수 있음

## 🔍 서포트 벡터 머신(Support Vector Machine)

**서포트 벡터 머신(SVM, Support Vector Machine)** 은 데이터를 가장 잘 분리하는 경계(결정 경계, Decision Boundary)를 찾는 알고리즘이다. 즉,  데이터 포인트 간의 **최적 결정 경계(Hyperplane)** 를 찾는 강력한 분류 알고리즘이다.

### SVM의 핵심 개념

- **하이퍼플레인(Hyperplane)**: 데이터를 분류하는 결정 경계(Decision Boundary)
- **마진(Margin)**: 하이퍼플레인과 가장 가까운 데이터 포인트 간의 거리
- **서포트 벡터(Support Vector)**: 마진을 정의하는 데이터 포인트
- **커널 트릭(Kernel Trick)**: 비선형 문제를 고차원 공간에서 선형 문제로 변환

![SVM 개념 시각화](/assets/img/2025-04-29/img_svm_example.png){: .w-75 .center}

> SVM 은 **마진(margin)을 최대화하는 결정 경계를 찾는 것이 목표**다. 이는 과적합을 방지하고 일반화 성능을 향상시킨다.
{: .prompt-tip}

**선형 분리 가능한(Linearly Separable)** 데이터셋이란, 하나의 직선(또는 초평면)으로 두 클래스를 완전히 구분할 수 있는 경우를 말한다.

***그런데 하나의 직선으로 두 클래스를 완전히 구분할 수 없는 경우가 더 많다!***

이럴 때, **커널 트릭(Kernel Trick)** 을 사용해서 이 문제를 해결할 수 있다.
### 커널 트릭(Kernel Trick)

선형적으로 분리할 수 없는 데이터를 분류하기 위해, SVM 은 **커널 함수(Kernel Function)** 를 사용하여 **데이터를 고차원 공간으로 매핑** 한다. 

이것을 **커널 트릭(Kernel Trick)** 이라고 한다.

![커널 트릭 개념 시각화](/assets/img/2025-04-29/img_kernel_trick_example.png){: .w-75 .center}
[출처: https://medium.com/analytics-vidhya/how-to-classify-non-linear-data-to-linear-data-bb2df1a6b781]

**주요 커널 함수**
- **선형 커널(Linear)**: $$K(x, y) = x^T y$$
- **다항식 커널(Polynomial)**: $$K(x, y) = (x^T y + c)^d$$
- **가우시안 RBF 커널(Gaussian RBF)**: $$K(x, y) = exp(-\gamma |x - y|^2)$$
- **시그모이드 커널(Sigmoid)**: $$K(x, y) = tanh(x^T y + c)$$

### SVM 의 장점

- 고차원 공간에서 효과적
- 메모리 효율적 (서포트 벡터만 사용)
- 다양한 커널 함수로 유연성
- 과적합에 강한 일반화 능력
### SVM 의 단점

- 대규모 데이터셋에서 훈련 시간이 오래 걸림
- 하이퍼파라미터 튜닝이 어려움
- 직접적인 확률 추정 제공하지 않음
- 비균형 데이터에 민감할 수 있음
