## 📝 학습내용

2주간의 Python 부트캠프가 끝났다.

처음 접하는 내용부터 이미 알고 있던 내용까지 다양한 주제를 다루었는데, 확실히 반복 학습을 통해 많은 부분이 명확해졌다.

부트캠프에서는 Python의 기본 문법을 시작으로 데이터 분석을 위한 다양한 도구와 기법을 배웠다. 크게 네 가지 영역에 집중했다.

### Python 기본 문법과 실용 팁

- 원글: [https://yuiyeong.github.io/posts/practical-python01/](https://yuiyeong.github.io/posts/practical-python01/)

기초 문법부터 시작해 클로저(Closure), 데코레이터(Decorator), 컬렉션(Collections) 등 실무에서 자주 사용되는 개념들을 학습했다.

특히 `str()`과 `repr()`의 차이, `eval()` 함수 활용, `Counter`를 이용한 요소 세기 등 실용적인 팁들이 유용했다.

### 웹 크롤링(with Selenium)

- 원글: [https://yuiyeong.github.io/posts/crawling-with-selenium/](https://yuiyeong.github.io/posts/crawling-with-selenium/)

웹사이트에서 데이터를 수집하는 방법으로 Selenium을 배웠다. 브라우저 자동화를 통해 동적 컨텐츠 수집, 스크롤 처리, JavaScript 실행 등을 구현해볼 수 있었다.

특히 웹드라이버 관리가 번거로웠는데, webdriver-manager를 통해 효율적으로 관리하는 방법을 배운 것이 큰 도움이 되었다.

### NumPy

- 원글: [https://yuiyeong.github.io/posts/numpy/](https://yuiyeong.github.io/posts/numpy/)

데이터 분석의 기초가 되는 NumPy 라이브러리를 배웠다.

ndarray의 기본 개념부터 다양한 생성 방법(arange, linspace), 연산(브로드캐스팅, 행렬 연산), 인덱싱과 슬라이싱, 배열 형태 변경(reshape, ravel) 등을 공부했다.

특히 배열을 다루는 다양한 접근법이 데이터 분석에 얼마나 효율적인지 깨달았다.

### Pandas를 이용한 데이터 분석

- 원글: [https://yuiyeong.github.io/posts/data-analysis-seoul-population/](https://yuiyeong.github.io/posts/data-analysis-seoul-population/)

데이터 분석에 필수적인 Pandas 라이브러리를 학습했다.

DataFrame과 Series의 기본 개념부터 시작해 데이터 로딩, 필터링, 그룹화, 피벗 테이블 생성 등 다양한 데이터 처리 기법을 배웠다.

특히 실습 부분에서 네이버 금융에서 크롤링한 주식 데이터를 Pandas로 처리하고 분석하는 과정이 인상적이었다.

삼성전자 등 주요 기업의 주가 데이터를 가져와 분석을 진행해보고, 서울시 인구 분포 데이터를 활용해 지역별 인구 밀도를 분석하고, 연령대별 인구 구성을 시각화하는 실습도 진행했다.

## 🌏 온라인 강의 소감

![bootcamp_online_lecture01.png](/assets/img/bootcamp_online_lecture01.png)

Python 문법, NumPy, Pandas, 데이터 시각화 등의 온라인 강의는 실시간 강의와는 또 다른 경험이었다.

Python부터 데이터 분석 기초까지의 내용이 약 3번 정도 반복되는 느낌이어서 때로는 무척 지루했다.

하지만 이러한 반복이 오히려 기초를 탄탄히 하는 데 도움이 되었다고 생각한다.

역시 반복이 최고의 기억 도구임은 맞았음을 경험해볼 수 있었다.

같은 내용을 다른 강사, 다른 예제, 다른 접근법으로 여러 번 접하다 보니 자연스럽게 개념이 체화되는 느낌이었다.

특히 NumPy의 브로드캐스팅이나 고급 인덱싱 같은 개념은 처음에는 어려웠지만, 여러 번의 반복 학습 후에는 훨씬 더 명확하게 이해할 수 있었다.

온라인 강의의 또 다른 장점은 자신의 페이스대로 학습할 수 있다는 점이었다.

이미 알고 있는 내용은 빠르게 넘어가고, 어려운 부분은 여러 번 반복해서 볼 수 있었다.
