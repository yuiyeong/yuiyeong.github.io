## 📚 비지도 학습(Unsupervised Learning)이란?

**학습용 라벨(Y_train)을 활용하지 않고** 입력 데이터(X)만으로 모델을 학습하는 방법론이다. 지도학습이 입력과 정답 쌍을 통해 특정 예측 작업을 수행하도록 학습하는 반면, 비지도학습은 **데이터 자체의 구조와 패턴을 파악**하는데 집중한다.

> 즉, 비지도학습은 라벨 없이 데이터 내부의 숨겨진 구조를 발견하는 기술로, 사람의 개입 없이 데이터로부터 자율적으로 학습한다.
{: .prompt-tip}

비지도학습은 다음과 같은 여러 방식으로 데이터를 분석한다.

- 입력 데이터 사이의 **유사성**과 **관계**를 활용
- 행렬 분해 등 별도 방법으로 데이터 행렬의 구조를 분석
- 입력값에 내재된 정보로 가상의 라벨을 생성
- 자기 자신(X)을 라벨로 활용하는 자기지도학습(Self-supervised learning)

이러한 접근 방식들은 각기 다른 비지도학습 알고리즘과 기법의 기초가 된다.

### 지도학습과 비지도학습의 차이

지도학습과 비지도학습의 가장 큰 차이점은 **학습 과정에서 라벨 데이터의 사용 여부**다. 

아이리스(Iris) 데이터셋을 예로 들어 두 방식의 차이를 살펴보자.

**분류 문제(지도학습)**

- 주어진 피처(꽃받침과 꽃잎의 길이/너비)를 입력값으로 사용
- 꽃의 종류(Setosa, Versicolor, Virginica)를 예측
- 모델의 예측과 실제 라벨을 비교해 오차를 줄이는 방향으로 학습

**군집화 문제(비지도학습)**

- 데이터의 유사성을 기반으로 자연스러운 그룹을 발견
- 비슷한(가까운) 데이터는 같은 그룹으로, 다른(먼) 데이터는 다른 그룹으로 분류
- 데이터 간의 내재적 관계와 패턴을 학습

이처럼 지도학습은 예측 정확도를 높이는 데 초점을 맞추지만, 비지도학습은 데이터의 구조와 패턴을 발견하는 데 중점을 둔다.

> 비지도 학습의 핵심 목표는 다음과 같다.
>
> - 데이터의 **잠재 구조**(latent structure) 발견
> - 데이터 포인트 간의 **관계와 패턴** 식별
> - 데이터의 **압축된 표현** 학습
> - 데이터 **생성 과정**의 모델링
{: .prompt-tip}


## 🤔 왜 비지도학습이 필요할까?

실세계 데이터의 대부분은 레이블이 없다. 

얀 르쿤(Yann LeCun)은 이를 케익에 비유했다.

> "웹상의 모든 데이터가 하나의 케익이라면, 라벨링된 데이터는 생크림 부분에 불과하다."

웹에서 수집된 텍스트, 사용자 행동 로그, 센서 데이터 등은 모두 명시적인 레이블 없이 수집된다.

*하지만 비지도학습이 필요한 이유는 단순히 라벨링 비용을 줄이기 위한 것이 아닌, 비지도학습만의 고유한 가치가 있다!*

 **지도학습과 비지도학습은 해결하려는 문제 자체가 다르다.** 
 
 지도 학습이 **특정 예측 작업의 성능을 최적화**하는 데 집중한다면, 비지도 학습은 **데이터의 본질적인 구조와 패턴을 이해**하는 데 중점을 둔다.

즉, 비지도 학습이 필요한 이유를 다음과 같이 적을 수 있다.
- **데이터 레이블링의 비용**: 대규모 데이터셋에 레이블을 부여하는 것은 시간과 비용이 많이 소요된다.
- **탐색적 데이터 분석**: 새로운 데이터셋에서 어떤 패턴이 있는지 알아내기 위한 첫 단계로 활용된다.
- **특징 추출**: 복잡한 고차원 데이터에서 유용한 특징을 자동으로 추출할 수 있다.
- **이상 탐지**: 정상 패턴에서 벗어나는 이상치를 찾아내는 데 효과적이다.
- **차원 축소**: 고차원 데이터를 저차원으로 변환하여 시각화하거나 후속 분석을 용이하게 한다.

> 비지도 학습은 마치 낯선 도시에 도착한 탐험가와 같다. 지도 없이도 도시의 구조, 핵심 랜드마크, 주요 경로를 파악해가는 과정이 비지도 학습의 본질이다.
{: .prompt-tip}

## 🌐 매니폴드 가설(Manifold Hypothesis)

비지도 학습의 이론적 기반 중 하나가 **매니폴드 가설**이다. 

이 가설은 ***고차원 데이터가 실제로는 더 낮은 차원의 매니폴드(다양체) 위에 존재***한다는 아이디어에 기초한다.

실생활에서 볼 수 있는 매니폴드의 예시는 다음과 같다.

- 종이를 구겨 만든 공: 3D 공간에 있지만 본질적으로는 2D 표면
- 실타래: 복잡하게 엉켜 있지만 본질적으로는 1D 선
- 인간의 얼굴 이미지: 수만 차원의 픽셀 공간이지만 실제로는 더 낮은 차원(나이, 표정, 조명 등)의 변화로 설명 가능

이처럼, 고차원 데이터(예: 이미지, 텍스트)도 실제로는 더 낮은 차원의 매니폴드 상에 분포한다는 것이 매니폴드 가설의 핵심

얼굴 이미지나 자연어와 같은 **실제 데이터는** 랜덤한 픽셀이나 단어 조합과는 달리, **특정한 패턴과 구조를 가지고 있다.**

- 실제 얼굴 이미지 데이터(from olivetti faces)
![olivetti 얼굴 이미지](/assets/img/2025-05-01/img_olivetti_faces.png){: .w-75 .center}

- 위 얼굴 이미지 데이터에서 무작위로 데이터 포인트를 골라서 시각화 했을 때

![olivetti 얼굴 이미지에서 무작위 샘플링](/assets/img/2025-05-01/img_ex_random_sampled_data_from_faces.png){: .w-75 .center}

특정 패턴과 구조로 데이터를 골라야, 얼굴처럼 보이는 이미지를 만들 수 있다. 즉, 얼굴 이미지 데이터는 고차원 공간(픽셀의 수에 해당하는 차원)에서 **저차원 매니폴드**를 형성하고 있으며, 이 매니폴드 위의 점들만이 의미 있는 얼굴 이미지를 나타낸다!

> 비지도 학습 알고리즘들은 이 매니폴드를 발견하고 모델링하는 데 중점을 둔다. 특히, 매니폴드 가설은 효과적인 차원 축소와 특징 학습의 이론적 근거가 된다. PCA, t-SNE, 오토인코더 등은 모두 데이터의 저차원 표현을 학습하는 방법이다.
{: .prompt-tip}

## ⬇️ 비지도 학습 예시: 차원 축소(Dimensionality Reduction)

차원 축소는 고차원 데이터를 더 낮은 차원으로 변환하는 과정이다. 이는 데이터 압축, 노이즈 제거, 시각화, 계산 효율성 향상 등의 목적으로 활용된다.

### 주요 차원 축소 기법

- **PCA(Principal Component Analysis)**: 데이터의 분산을 최대화하는 방향으로 차원을 축소한다.
- **t-SNE(t-Distributed Stochastic Neighbor Embedding)**: 국소적 구조를 보존하며 시각화에 특화된 기법이다.
- **UMAP(Uniform Manifold Approximation and Projection)**: t-SNE보다 계산 효율성이 높으며 전역 구조도 더 잘 보존한다.
- **오토인코더(Autoencoder)**: 신경망을 사용하여 데이터의 압축된 표현을 학습한다.

### 차원 축소의 실제 활용 사례

#### 1. 유전체학에서의 활용

- **기술**: PCA, t-SNE 
- **적용 사례**: 단일 세포 RNA 시퀀싱 데이터 분석

유전체학에서는 수천 개의 유전자 발현 데이터를 다룬다. 이런 고차원 데이터에서 세포 유형을 식별하기 위해 차원 축소 기술이 필수적이다.

예를 들어, 10X Genomics의 연구팀은 PCA 와 t-SNE 를 조합하여 수만 개의 단일 세포 RNA 시퀀싱 데이터를 분석했다. 먼저 PCA 로 수천 차원의 유전자 발현 데이터를 50차원으로 축소한 후, t-SNE를 적용하여 2D로 시각화했다. 이를 통해 이전에 알려지지 않은 희귀 세포 유형을 발견하고, 암 조직 내 면역 세포의 새로운 하위 집단을 식별할 수 있었다.

#### 2. 추천 시스템에서의 활용

- **기술**: SVD(Singular Value Decomposition), 행렬 분해
- **적용 사례**: Netflix 영화 추천 엔진

Netflix는 SVD를 기반으로 한 행렬 분해 기법을 사용하여 사용자-영화 평점 행렬의 차원을 축소한다. 수백만 명의 사용자와 수만 개의 영화로 구성된 희소 행렬에서, 잠재 요인(latent factors)을 추출하여 사용자의 취향과 영화의 특성을 약 100-300차원으로 표현한다.

이 저차원 표현은 '사용자가 보지 않은 영화에 대한 평점'을 예측하는 데 사용되며, 이를 기반으로 개인화된 추천이 이루어진다. Netflix의 경우 이 방식을 통해 추천 정확도를 10% 이상 향상시켰다고 보고했다.

> 이후로, PCA 를 진행하는 알고리즘의 내부에서 SVD 를 사용하는 경우가 많아졌다!
{: .prompt-tip}

#### 3. 이미지 검색 엔진에서의 활용

- **기술**: 컨볼루션 오토인코더, VGG, ResNet 등의 특징 추출기
- **적용 사례**: Pinterest 의 시각적 검색 시스템

Pinterest는 수십억 개의 이미지를 효과적으로 색인화하고 검색하기 위해 차원 축소 기술을 활용한다. 이미지는 처음에 CNN(Convolutional Neural Network)을 통해 4096차원의 특징 벡터로 변환된 후, PCA나 양자화 기법을 통해 더 작은 차원(약 128-512차원)으로 축소된다.

이러한 압축된 표현은 K-최근접 이웃(K-NN) 알고리즘을 사용한 고속 검색을 가능하게 하며, 사용자가 유사한 시각적 콘텐츠를 빠르게 찾을 수 있게 한다. Pinterest의 경우 이 시스템을 통해 시각적 검색 결과의 정확도를 30% 이상 향상시켰다.

#### 4. 금융 분야에서의 활용

- **기술**: 커널 PCA, 오토인코더
- **적용 사례**: 신용 위험 평가 모델

JP Morgan과 같은 금융 기관은 차원 축소 기법을 활용하여 고객의 신용 위험을 평가한다. 수백 개의 변수(신용 이력, 소득, 자산, 부채 비율 등)로 구성된 고차원 데이터에서 중요한 위험 요소를 추출하기 위해 비선형 차원 축소 기법을 적용한다.

이렇게 추출된 저차원 특징은 고객의 신용 점수 계산, 대출 승인 결정, 이상 거래 탐지 등에 활용된다. 차원 축소를 통해 모델의 해석 가능성이 향상되고, 과적합 위험이 감소하며, 계산 효율성이 개선된다.

## 🤬 PCA(Principal Component Analysis)
### PCA 의 수학적 이해

PCA 는 데이터의 분산을 최대화하는 직교 기저를 찾는 과정이다.

$$ \max_{W: W^TW=I} \text{Tr}(W^T X^T X W) $$

여기서,
- 데이터 행렬 $$X$$
	- 이것은 원본 데이터를 나타내는 행렬
	- 보통 각 행은 하나의 샘플(데이터 포인트)이고, 각 열은 특성(feature)을 나타낸다.
	- 예를 들어, $$X$$가 100개의 이미지와 각 이미지의 784개 픽셀 값을 담고 있다면, $$X$$는 $$100 \times 784$$ 행렬이 된다.

- 투영 행렬 $$W$$
	- 이것은 원본 데이터를 새로운 좌표계로 변환하는 행렬
	- 각 열은 새로운 좌표계의 축(주성분)을 나타낸다.
	- PCA에서는 이 행렬이 데이터의 분산을 최대한 보존하는 방향을 찾는 것이 목표

- $$W^TW=I$$ 조건
	- 이 조건은 $$W$$의 열들이 서로 직교해야 함을 의미합니다(orthogonal)
	- $$I$$는 단위행렬(identity matrix)
	- 이 조건은, 찾고자 하는 새로운 축들이 서로 수직(직교)이어야 한다는 제약을 나타낸다.

- $$X^TX$$ 행렬
	- 이것은 데이터의 공분산 행렬(데이터가 평균 중심화되었을 때)
	- 이 행렬은 변수들 간의 관계를 나타낸다.

- $$\text{Tr}()$$ (트레이스)
	- 행렬의 대각합, 즉 대각선 요소들의 합을 의미
	- 수학적으로 $$\text{Tr}(A) = \sum_i A_{ii}$$
	- PCA 맥락에서는 트레이스가 전체 분산을 나타낸다.

**전체 수식의 의미**
- PCA는 데이터의 분산을 최대화하는 방향(주성분)을 찾고자 하는 것이다.
- $$\text{Tr}(W^T X^T X W)$$는 **새 좌표계에서의 데이터 분산**을 의미한다.
- 즉, "직교 제약 조건 하에서 데이터의 분산을 최대화하는 변환 행렬 $W$를 찾아라"라는 의미이다.

**고유값(Eigenvalues)**

고유값은 선형대수학에서 정방행렬 $$A$$에 대해, $$\vec{v}$$와 스칼라 $$\lambda$$가 있어서 $$A\vec{v} = \lambda \vec{v}$$ 를 만족할 때, $$\lambda$$를 고유값(Eigenvalues)이라고 하고, $$\vec{v}$$를 고유벡터(Eigenvector)라고 한다.

직관적으로, 고유벡터($$\vec{v}$$)는 행렬 $$A$$에 의해 변환될 때, 방향은 유지되고 크기만 $$\lambda$$배 변하는 특별한 벡터입니다.

- PCA에서 **고유값은 각 주성분이 설명하는 데이터의 분산**을 의미한다. 
- 고유값이 클수록 해당 방향(고유벡터)으로의 데이터 분산이 크다는 것을 의미

### SVD(Singular Value Decomposition)

SVD 는 PCA 보다 더 일반적인 행렬 분해 방법으로, 어떤 행렬이든 세 개의 행렬로 분해할 수 있다.

임의의 행렬 A를 다음과 같이 분해할 수 있다.

$$ A = U\Sigma V^T $$

여기서,
- $$U$$: m×m 직교행렬(왼쪽 특이벡터)
- $$\Sigma$$: m×n 대각행렬(특이값)
- $$V^T$$: n×n 직교행렬의 전치(오른쪽 특이벡터의 전치)


**특이값(Singular Values)**

SVD 에서는 특이값(Singular Values)이라는 용어와 특이벡터(Singular Vector)라는 용어를 사용한다. 

특이값은 행렬이 특정 방향으로 얼마나 "늘어나는지"를 나타냅니다.

### PCA와 SVD 의 관계

PCA와 SVD 사이에는 밀접한 관계가 있다!

- PCA 는 데이터의 공분산 행렬 $$X^TX$$에 대한 고유값 분해를 수행합니다.
- SVD 는 데이터 행렬 $$X$$ 자체를 분해합니다.

수학적으로 관계를 풀어보자면,
- PCA의 고유값 = SVD의 특이값의 제곱
- 즉, $$\lambda_i = \sigma_i^2$$ (여기서 $$\lambda_i$$는 고유값, $$\sigma_i$$는 특이값)
- PCA 의 주성분 = SVD 의 오른쪽 특이벡터 (V의 열)

다음 코드로 이 관계를 확인할 수 있다.

```python
import numpy as np
from sklearn.datasets import load_iris

# 데이터 로드
iris = load_iris()
X = iris.data  # shape: (150, 4)
X_centered = X - np.mean(X, axis=0)  # 데이터 중심화

# 방법 1: PCA (고유값 분해 사용)
cov_matrix = np.cov(X_centered, rowvar=False)
eigenvalues, eigenvectors = np.linalg.eigh(cov_matrix)
# 내림차순 정렬
idx = np.argsort(eigenvalues)[::-1]
eigenvalues = eigenvalues[idx]  # shape: (4,)
eigenvectors = eigenvectors[:, idx]  # shape: (4, 4)

# 방법 2: SVD
U, singular_values, Vt = np.linalg.svd(X_centered, full_matrices=False)

# 관계 확인: 고유값 = 특이값의 제곱
print("PCA 고유값:")
print(eigenvalues)
print()
print("SVD 특이값의 제곱:")
print(singular_values**2 / (X_centered.shape[0] - 1))  # 샘플 수 보정
# 출력
# PCA 고유값:
# [4.22824171 0.24267075 0.0782095  0.02383509]
# 
# SVD 특이값의 제곱:
# [4.22824171 0.24267075 0.0782095  0.02383509]


# 주성분 방향 비교: PCA 고유벡터 vs SVD 오른쪽 특이벡터
print("PCA 첫 번째 주성분(고유벡터):")
print(eigenvectors[:, 0])
print()
print("SVD 첫 번째 오른쪽 특이벡터:")
print(Vt[0])  # 부호가 반대일 수 있음
# 출력
# PCA 첫 번째 주성분(고유벡터):
# [-0.36138659  0.08452251 -0.85667061 -0.3582892 ]
# 
# SVD 첫 번째 오른쪽 특이벡터:
# [ 0.36138659 -0.08452251  0.85667061  0.3582892 ]
```


### PCA와 SVD 중 어떤 것을 선택해야 할까?

- PCA 선택 상황
    - 데이터의 분산을 최대화하는 방향이 중요할 때
    - 공분산 행렬을 직접 분석하고 싶을 때
    - 전통적인 차원 축소 알고리즘을 사용하고 싶을 때
    - 계산 효율성: 특성 수 < 샘플 수일 때 유리

- SVD 선택 상황
    - 직사각형 행렬(비정방행렬)을 다룰 때
    - 희소 행렬(sparse matrix)을 처리할 때
    - 추천 시스템과 같은 협업 필터링에서
    - 수치적 안정성이 중요할 때
    - 계산 효율성: 특성 수 > 샘플 수일 때 유리

> PCA 와 SVD 는 원래 통계학과 수학에서 각각 발전한 별개의 기법이었다. PCA는 고유값(eigenvalues)으로 공분산 행렬을 분석하고, SVD는 특이값(singular values)으로 임의 행렬을 분해한다. 두 방법 사이의 수학적 관계는 '고유값 = 특이값²'으로 표현된다.
> 
> 2006년 Netflix Prize를 기점으로 SVD 기반 알고리즘이 추천 시스템의 표준이 되었는데, 이는 SVD 가 희소 행렬과 결측값 처리에 더 효과적이었기 때문이다. 
> 
> 이 전환점은 머신러닝에서 행렬 분해 기법의 중요성을 크게 높인 역사적 사건이었다.

## 👁️ 비지도 학습 예시: 시각화(Visualization)

데이터 시각화는 비지도 학습의 중요한 응용 분야이다. 고차원 데이터를 2D 또는 3D로 축소하여 사람이 직관적으로 이해할 수 있게 만든다.

### 대표적인 시각화 기법

- **t-SNE**: 국소적 구조를 보존하면서 클러스터를 잘 분리한다.
- **UMAP**: t-SNE보다 빠르며, 전역 구조도 더 잘 보존한다.
- **Isomap**: 데이터의 측지선 거리(geodesic distance)를 보존하는 방식으로 작동한다.
- **MDS(Multidimensional Scaling)**: 고차원 공간의 거리 관계를 저차원에서 보존하려고 시도한다.

t-SNE의 목적 함수는 다음과 같다.

$$ \min_{Y} KL(P||Q) = \sum_{i \neq j} p_{ij} \log \frac{p_{ij}}{q_{ij}} $$

여기서,
- $$P$$는 원본 고차원 공간에서의 확률 분포
- $$Q$$는 저차원 공간에서의 확률 분포
- $$KL$$은 쿨백-라이블러 발산


### t-SNE 와 PCA 의 시각화 비교

> [mnist](https://ko.wikipedia.org/wiki/MNIST_%EB%8D%B0%EC%9D%B4%ED%84%B0%EB%B2%A0%EC%9D%B4%EC%8A%A4) 데이터셋은 0 ~ 9 까지의 숫자에 대한 흑백 손글씨 이미지로 크기가 28 x 28(784) 이다.
{: .prompt-tip}

다음 코드를 실행하여, mnist 데이터셋을 2차원으로 축소 했을 때의 시각화 결과를 비교해보았다.

```python
import time  
  
from sklearn.datasets import fetch_openml  
from sklearn.decomposition import PCA  
from sklearn.manifold import TSNE

# MNIST 데이터셋 일부 로드  
mnist = fetch_openml("mnist_784", version=1, parser="auto")  
X = mnist.data[:3000] / 255.0  # 정규화, shape: (3000, 784)
y = mnist.target[:3000].astype(int)  # shape: (3000,)
  
random_state = 1234  

# PCA 적용  
t0 = time.time()  
pca = PCA(n_components=2, random_state=random_state)  # 2차원으로 축소  
X_pca = pca.fit_transform(X)  
t_pca = time.time() - t0  
print(f"PCA 실행 시간: {t_pca:.2f}초")  # PCA 실행 시간: 0.02초

# t-SNE 적용  
t0 = time.time()  
tsne = TSNE(n_components=2, random_state=random_state)  # 2차원으로 축소  
X_tsne = tsne.fit_transform(X)  
t_tsne = time.time() - t0  
print(f"t-SNE 실행 시간: {t_tsne:.2f}초"). # t-SNE 실행 시간: 4.10초

# 결과 시각화  
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(16, 7))  
  
# PCA 결과  
scatter1 = ax1.scatter(X_pca[:, 0], X_pca[:, 1], c=y, cmap="tab10", alpha=0.8)  
ax1.set_title(f"MNIST with PCA({t_pca:.2f}sec)")  
ax1.grid(alpha=0.3)  
fig.colorbar(scatter1, ax=ax1, label="Numbers")  
  
# t-SNE 결과  
scatter2 = ax2.scatter(X_tsne[:, 0], X_tsne[:, 1], c=y, cmap="tab10", alpha=0.8)  
ax2.set_title(f"MNIST with t-SNE({t_tsne:.2f}sec)")  
ax2.grid(alpha=0.3)  
fig.colorbar(scatter2, ax=ax2, label="Numbers")  
  
plt.tight_layout()  
plt.show()
```

- 시각화 결과

![PCA vs t-SNE](/assets/img/2025-05-01/img_comparing_between_pca_and_tsne.png)

- 두 기법의 시각적 결과 비교  
  - PCA는 선형 기법으로 계산이 빠르지만, 비선형 관계를 잘 포착하지 못할 수 있다.  
  - t-SNE는 비선형 기법으로 계산이 느리지만, 복잡한 구조를 더 잘 보존할 수 있다.  
  - MNIST 데이터에서 t-SNE는 일반적으로 같은 숫자끼리 더 잘 군집화하는 경향이 있다.  
  
일반적으로 t-SNE는 PCA보다 계산 비용이 크지만, 고차원 데이터의 군집 구조를 더 잘 보존하는 경향이 있다.

**PCA 결과가 더 섞여 있는 이유**
- **선형 변환의 한계**
    - PCA는 *선형 차원 축소 기법*이다.
    - 데이터의 *분산이 가장 큰 방향(주성분)을 찾아 투영*하는 방식으로 작동한다.
    - 그래서 데이터의 비선형적 관계나 복잡한 구조를 잘 포착하지 못하는 것이다.
- **전역적 구조 보존**
    - PCA는 데이터 *전체의 분산을 최대화*하는 방향을 찾는다.
    - 이 과정에서 지역적인 구조나 클래스별 *특성이 희석*될 수 있다.

**t-SNE가 군집화가 잘되는 이유**
- **비선형 매니폴드 학습**
    - t-SNE는 *비선형 차원 축소 알고리즘*이다.
    - 데이터 포인트 간의 *유사도를 보존*하는 데 중점을 둡니다.
    - 고차원 공간에서 가까운 점들은 저차원 공간에서도 가까이 위치하도록 합니다.
- **지역적 구조 보존**
    - t-SNE는 특히 지역적 구조 보존에 뛰어나다.
    - 같은 클래스(숫자)에 속하는 데이터 포인트들은 서로 유사한 경향이 있어 군집을 형성한다.
    - 이는 숫자 분류와 같은 문제에서 시각적으로 명확한 구분을 제공한다.
- **확률적 접근법**
    - t-SNE는 확률 분포를 사용하여 데이터 포인트 간의 관계를 모델링합니다.
    - 이를 통해 복잡한 데이터 구조를 더 잘 반영할 수 있습니다.

**실용적 의미**
- 탐색적 데이터 분석
    - t-SNE는 데이터의 군집 구조를 시각적으로 파악하는 데 매우 유용하다.
    - 특히 분류 문제에서 클래스 간 구분을 시각화하는 데 효과적이다.
- 계산 비용과 속도 차이    
    - t-SNE는 PCA보다 계산 비용이 높고 실행 시간이 길다(코드에서도 볼 수 있듯이).
    - 대규모 데이터셋에서는 PCA로 차원을 먼저 축소한 후 t-SNE를 적용하는 방식도 자주 사용된다.
- 목적에 따른 선택
    - 빠른 차원 축소나 특성 추출이 필요하면 PCA가 적합하다.
    - 복잡한 데이터 구조를 시각화하거나 군집을 명확히 보고 싶다면 t-SNE가 더 나은 선택이다.

### 시각화의 실제 활용 사례

#### 1. 제약 산업에서의 약물 발견

- **기술**: t-SNE, UMAP 
- **적용 사례**: Merck의 약물 후보 분자 시각화

제약회사 Merck는 t-SNE와 UMAP을 사용하여 수백만 개의 분자 화합물 라이브러리를 2D 공간에 시각화한다. 각 분자는 수백 개의 물리화학적 속성과 구조적 특징으로 표현되는 고차원 객체다.

시각화를 통해 연구자들은 비슷한 특성을 가진 분자 그룹을 식별하고, 약물 타겟에 대한 잠재적 후보를 효율적으로 탐색할 수 있다. 이는 실험실 테스트 전에 유망한 후보를 선별하는 데 도움이 되어, 신약 개발 시간과 비용을 크게 절감한다.

한 사례에서 Merck는 이 접근법을 통해 항암제 개발 과정에서 이전에 간과된 분자 그룹을 발견하여 새로운 후보 물질을 식별했다고 보고했다.

#### 2. 사이버 보안에서의 네트워크 트래픽 분석

- **기술**: UMAP, t-SNE 
- **적용 사례**: Darktrace의 비정상 네트워크 트래픽 탐지

사이버 보안 기업 Darktrace는 UMAP과 t-SNE를 활용하여 네트워크 트래픽 데이터를 시각화한다. 패킷 크기, 프로토콜, 대상 IP, 시간적 패턴 등 수십 가지 특성으로 구성된 고차원 데이터를 2D 맵으로 변환한다.

이 시각화를 통해 보안 분석가는 정상 트래픽 패턴과 다른 이상점(잠재적 보안 위협)을 직관적으로 식별할 수 있다. 특히 DDoS 공격, 데이터 유출, 랜섬웨어 활동과 같은 복잡한 위협 패턴이 시각적으로 뚜렷한 클러스터로 나타난다.

한 금융 기관에서는 이 접근법을 통해 기존 규칙 기반 시스템이 놓친 지능형 악성코드를 탐지하여 잠재적 데이터 유출을 막았다고 한다.

#### 3. 고객 행동 분석

- **기술**: t-SNE, UMAP, 인터랙티브 시각화 
- **적용 사례**: Airbnb의 사용자 여행 경로 분석

Airbnb는 수억 명의 사용자가 웹사이트와 앱에서 어떻게 상호작용하는지 이해하기 위해 t-SNE와 UMAP을 활용한다. 검색 쿼리, 클릭 패턴, 체류 시간, 필터 사용 등 수백 개의 행동 지표가 고차원 데이터를 구성한다.

이 데이터를 2D로 시각화함으로써 Airbnb는 비슷한 행동 패턴을 가진 사용자 그룹을 식별하고, 각 그룹에 맞춤화된 경험을 제공할 수 있다. 예를 들어, 가족 여행객, 비즈니스 여행객, 모험 여행객 등의 자연스러운 세그먼트가 시각화에서 발견된다.

Airbnb는 이 접근법을 통해 검색 알고리즘을 최적화하고 개인화된 추천을 개선하여, 예약 전환율을 15% 이상 증가시켰다고 보고했다.

#### 4. 생물정보학에서의 유전자 발현 분석

- **기술**: t-SNE, UMAP 
- **적용 사례**: Broad Institute의 암 유전자 발현 데이터 시각화

Broad Institute 연구자들은 암 게놈 아틀라스(TCGA) 데이터셋의 유전자 발현 패턴을 시각화하기 위해 t-SNE와 UMAP을 활용했다. 20,000개 이상의 유전자 발현 수준으로 구성된 이 고차원 데이터는 다양한 암 유형과 하위 유형의 분자적 특성을 나타낸다.

2D 시각화를 통해 연구자들은 유사한 분자적 특성을 공유하는 암 샘플 그룹을 식별하고, 이전에 알려지지 않은 암 하위 유형을 발견할 수 있었다. 특히, 임상적으로는 같은 암으로 분류되지만 분자적으로는 다른 특성을 가진 유형들이 시각화에서 명확히 구분되었다.

이 접근법을 통해 연구자들은 특정 암 하위 유형에 대한 맞춤형 치료법을 개발하는 데 중요한 통찰을 얻었으며, 정밀 의학 발전에 기여했다.

> 데이터 시각화는 고차원 데이터의 패턴을 인간이 직관적으로 이해할 수 있게 해주는 강력한 도구다. t-SNE와 UMAP 같은 기법은 복잡한 관계를 보존하면서 데이터를 저차원으로 표현할 수 있다.

## 🧩 비지도 학습 예시: 군집화(Clustering)

군집화는 유사한 데이터 포인트들을 그룹화하는 과정이다. 이는 데이터의 구조를 이해하고, 세그먼트를 발견하며, 관련 항목을 식별하는 데 활용된다.

### 주요 군집화 알고리즘

- **K-means**: 데이터를 K개의 군집으로 나누며, 각 군집은 중심점(centroid)을 가진다.
- **계층적 군집화(Hierarchical Clustering)**: 데이터 포인트를 단계적으로 병합하거나 분할한다.
- **DBSCAN(Density-Based Spatial Clustering of Applications with Noise)**: 밀도 기반 군집화로, 임의 형태의 군집을 발견할 수 있다.
- **가우시안 혼합 모델(Gaussian Mixture Model)**: 여러 가우시안 분포의 혼합으로 데이터를 모델링한다.

## 📝 비지도 학습 예시: 단어의 임베딩(Word to Vector)

임베딩(Embedding)은 복잡한 데이터(텍스트, 이미지 등)를 의미적 연산이 가능한 벡터 공간에 매핑하는 기술이다. 

단어 임베딩(Word to Vector)은 자연어 처리에서 단어를 의미가 보존되는 방식으로 벡터 공간에 매핑하는 대표적인 임베딩 기술이다. 이는 자연어 처리의 핵심 요소로, 의미적으로 유사한 단어들은 벡터 공간에서 서로 가깝게 위치하게 된다.

### 주요 단어 임베딩 기법

- **Word2Vec**: 문맥에서 주변 단어를 예측하거나(CBOW), 주변 문맥에서 중심 단어를 예측하는(Skip-gram) 방식으로 학습한다.
- **GloVe**: 단어 동시 출현 통계를 활용하여 벡터를 학습한다.
- **FastText**: 단어의 하위 단위(서브워드)를 고려하여 임베딩을 학습한다.
- **BERT 등의 컨텍스트 임베딩**: 문맥에 따라 단어의 의미가 달라지는 특성을 반영한다.
- **한국어 특화 임베딩**: KoBERT, KoGPT, fastText-ko, Word2Vec-ko, KorBERT 등 한국어의 교착어적 특성과 형태소 구조를 고려한 임베딩 모델이 있다.

## 🎨 비지도 학습 예시: 생성 모델(Generative Model)

생성 모델은 데이터의 분포를 학습하여 새로운 샘플을 생성할 수 있는 모델이다. 이는 이미지, 텍스트, 음악 등 다양한 종류의 데이터를 생성하는 데 활용된다.

### 주요 생성 모델

- **GAN(Generative Adversarial Network)**: 생성자와 판별자 네트워크가 경쟁하며 학습한다.
- **VAE(Variational Autoencoder)**: 데이터의 확률적 분포를 학습하는 오토인코더의 변형이다.
- **확산 모델(Diffusion Models)**: 점진적으로 노이즈를 제거하며 데이터를 생성한다.
- **자기회귀 모델(Autoregressive Models)**: 이전 출력을 기반으로 다음 출력을 순차적으로 생성한다.
- **대규모 언어 모델(LLM)**: GPT, LLaMA, Claude 등의 모델로, 자기회귀적 특성을 가진 생성 모델의 일종이다. 방대한 텍스트 데이터로 학습되어 다양한 자연어 생성 작업을 수행한다.

##  📊 고차원 데이터란?
### 우선, 차원이란?

![](/assets/img/2025-05-01/img_example_of_high_dim_data.png)

차원은 데이터를 표현하는 데 필요한 독립적인 변수의 수를 의미한다. 

- 예를 들어)
- **1차원 데이터**: 선 위의 점 (x)
- **2차원 데이터**: 평면 위의 점 (x, y)
- **3차원 데이터**: 공간 속의 점 (x, y, z)
- **n차원 데이터**: n개의 특성을 가진 점 (x₁, x₂, ..., xₙ)

실제 데이터셋의 차원은 다음과 같이 다양하다.

- **이미지**: 224×224 RGB 이미지는 224×224×3 = 150,528차원
- **텍스트**: 10,000개 단어 어휘로 원-핫 인코딩된 텍스트는 10,000차원
- **유전체**: 인간 유전체 데이터는 수백만 차원
- **센서 데이터**: IoT 기기에서 수집된 다중 센서 데이터는 수천 차원에 달할 수 있다

### 왜 고차원 데이터가 필요할까?

> 현실은 원래 고차원이다!
{: .prompt-tip}

특히, 현대 하드웨어의 발전으로 인해 우리가 **수집하는 데이터의 차원은 계속해서 증가**하고 있다.

- **스마트폰 카메라**: 최신 아이폰의 4800만 화소(48MP) 사진은 RGB 채널을 고려할 때 1억 4400만 차원의 데이터다.
- **비디오 데이터**: 4K 해상도(3840×2160) 동영상의 각 프레임은 약 2490만 차원이며, 초당 30프레임이면 초당 약 7억 5천만 차원의 데이터가 생성된다.
- **오디오 데이터**: CD 품질(44.1kHz, 16bit)의 스테레오 음악은 초당 약 7만 차원의 데이터를 생성한다.

이러한 고차원 데이터를 축소하면(예: 이미지 크기 줄이기) 처리는 쉬워지지만 정보 손실이 불가피하다. 

현실의 많은 문제는 본질적으로 고차원적이어서, 과도한 차원 축소는 중요한 패턴을 놓치게 할 수 있다.

## 💻 고차원에서 생기는 문제점: 컴퓨터 자원의 사용량

차원이 증가하면서 발생하는 첫 번째 문제는 **계산 자원의 기하급수적 증가**다.

고차원 데이터에서 계산 복잡성이 증가하는 원인은 다음과 같다.

- **저장 공간**: 차원이 증가할수록 필요한 메모리가 선형적으로 증가한다.
- **연산 복잡도**: 많은 알고리즘의 연산 복잡도는 차원에 비례하여 증가한다.
- **전체 데이터 포인트**: 차원이 증가할수록 필요한 데이터 포인트의 수가 지수적으로 증가한다.

## 🌀 차원의 저주(Curse of Dimensionality)


차원의 저주는, 차원이 증가함에 따라 데이터가 공간에서 점점 더 희소해지는 현상이다. 

이로 인해 다음과 같은 문제가 발생한다.
1. **데이터 희소성**: 차원이 증가할수록 같은 밀도를 유지하기 위해 필요한 데이터 포인트 수가 지수적으로 증가한다.
2. **거리의 의미 상실**: 고차원에서 모든 점들 사이의 거리가 비슷해지는 현상이 발생한다.
3. **과적합 위험 증가**: 데이터에 비해 모델 파라미터가 너무 많으면 과적합이 발생하기 쉽다.

### 차원의 저주 완화 방법

차원의 저주를 완화하기 위한 방법들:

- **차원 축소**: PCA, t-SNE, UMAP 등을 통해 데이터의 중요한 특성만 보존한다.
- **특징 엔지니어링**: 도메인 지식을 활용하여 중요한 특징만 선별한다.
- **정규화(Regularization)**: L1, L2 정규화 등을 통해 모델의 복잡성을 제한한다.
- **앙상블 방법**: 여러 단순 모델을 결합하여 고차원 문제를 해결한다.
- **매니폴드 가정 활용**: 데이터가 저차원 매니폴드에 있다는 가정 하에 적절한 알고리즘을 선택한다.

> 차원의 저주는 고차원 데이터 분석의 핵심 도전과제로, 데이터 희소성과 거리 측정의 의미 상실을 초래한다. 이를 인식하고 적절한 차원 축소 및 특징 선택 기법을 활용하는 것이 중요하다. 
{: .prompt-tip}

## 🧠 직관적으로 이해하기엔 너무나 힘든 고차원 공간

> 제프리 힌튼 said "To deal with a 14-dimensional space, visualize a 3D space and say 'fourteen' to yourself very loudly. Everyone does it."

고차원으로 갈수록 직관이라는 이름의 함정에 빠질 수 있다. 인간의 뇌는 3차원 이상의 공간을 직접 시각화하거나 이해하는 데 근본적인 한계가 있다.

### 고차원 공간에서 나타나는 직관적으로 이해하기 어려운 현상들

고차원 공간에서는 우리의 일상적 직관을 배반하는 현상들이 발생한다.
- **부피 역설**: 고차원 큐브에서 대부분의 부피는 모서리 근처에 집중된다.
- **거리 붕괴**: 모든 점 쌍 사이의 거리가 거의 동일해진다.
- **빈 공간 현상**: 데이터 포인트 간 거리가 멀어져 밀도 기반 알고리즘이 효과적이지 않다.
- **과적합 용이성**: 차원이 증가할수록 데이터를 완벽하게 분리할 수 있는 결정 경계가 많아진다.

### 실제 응용에서의 직관 극복 방법

- **시각화 도구 활용**: t-SNE, UMAP 등을 사용하여 고차원 데이터를 2D/3D로 투영한다.
- **차원 축소**: 분석 전에 차원 축소 기법을 적용하여 해석 가능성을 높인다.
- **특징 중요도 분석**: 모델의 특징 중요도를 분석하여 핵심 차원을 식별한다.
- **매니폴드 학습**: 데이터의 내재된 저차원 구조를 학습한다.
- **모델 해석 도구**: SHAP, LIME 등의 도구를 활용하여 모델의 예측을 해석한다.

> 고차원 공간에서의 직관적 한계를 인식하고, 이를 보완하기 위한 도구와 방법론을 활용하는 것이 중요하다. 수학적 이론과 시각화 도구를 함께 사용하면 고차원 데이터의 복잡한 구조를 더 잘 이해할 수 있다.
